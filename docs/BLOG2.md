# Introducing Plux: A New Way to Talk to Your Files

## Goodbye copy-paste. Hello `+`.

We’ve all been there—trying to use ChatGPT, Claude, or Gemini to ask questions about our files… only to copy-paste text endlessly, struggle with file formats, or hit token limits.

**Plux** changes that. It's a local-first, privacy-friendly AI interface where you simply browse your folders and click `+` to add context. No commands, no code, no setup. Just a button.

## Built for Everyone, Not Just Developers

Unlike AI IDEs like Cursor, Plux isn’t just for coding. It works with **PDFs, Word docs, videos, datasets, scripts, notebooks, Markdown, and more**. If it's a file, Plux can help you ask better questions about it.

Writers, researchers, students, analysts, content creators—Plus gives anyone an intuitive way to use state-of-the-art AI tools without technical overhead.

## Works with Your Favorite Models

Already integrated:
- ✅ Claude
- ✅ OpenAI
- ✅ Gemini
- ✅ Any MCP-compatible model (via plugin)

Plux doesn't lock you in. Models are plugins. The file interface is yours.

## No Commands. No Confusion.

You don’t need to type `@file`, `@folder`, or special commands. Just click `+` next to any file or folder, and it becomes part of the AI conversation.

Want to ask about an entire folder? Click `+` next to it. Want to remove context? Click `-`. That’s it.

## Powered by MCP — but Invisible to the User

Under the hood, Plux uses the **Model Context Protocol (MCP)** to connect your files to any LLM. But users don’t need to care. It just works.

Want more models? Browse the plugin marketplace. Want more control? Click to inspect or re-order your context list.
